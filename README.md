# COVID-19 Data Analysis

A Python-based COVID-19 case study analyzing confirmed cases, deaths, and recoveries across countries. The project includes data cleaning, **wide-to-long transformation, merging multiple datasets, country-wise and monthly aggregation, peak daily case analysis, and death/recovery rate calculations**, with visualizations using Pandas and Matplotlib.

## 🛠️ Tools

Python • Pandas • NumPy • Matplotlib
